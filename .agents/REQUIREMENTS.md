# Functional Requirements

## User

A User can:

- Sign in to the system
- Change their password
- View their own profile
- Update personal information

---

## Field Technician

A Field Technician can:

- View assigned work orders
- Accept or reject a work order
- Start a service
- Pause a service
- Resume a service
- Complete a service
- Upload photos and attachments
- Add service notes
- Capture the customer's signature
- View their work history

---

## Supervisor

A Supervisor can:

- Create work orders
- Update work orders
- Cancel work orders
- Assign technicians
- Reassign technicians
- Monitor work order status
- View team performance
- Generate operational reports

---

## Administrator

An Administrator can:

- Manage users
- Manage roles and permissions
- Register customers
- Register service categories
- Configure system settings
- View audit logs
- Access system-wide reports
