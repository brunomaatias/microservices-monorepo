# Database Strategy

## PostgreSQL

PostgreSQL is used for transactional and relational data.

Examples:

- Users
- Customers
- Work Orders
- Technicians
- Service Categories

Reasons:

- Strong consistency
- ACID transactions
- Complex relationships
- SQL capabilities

---

## MongoDB

MongoDB is used for document-oriented and high-volume data.

Examples:

- Audit logs
- Event history
- Notification history
- Activity logs

Reasons:

- Flexible schema
- Fast writes
- Large document storage
- Event sourcing support
